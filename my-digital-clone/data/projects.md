# Projects Portfolio

## 1. Personal Digital Clone (Hybrid RAG System)
- **Tech Stack:** Python, Streamlit, SentenceTransformers (`all-MiniLM-L6-v2`), BM25Okapi, Groq API, NumPy
- **Description:** Built an interactive AI digital clone capable of answering questions strictly grounded in my personal notes and academic documents. Implemented a Hybrid Retrieval pipeline combining lexical search (BM25) and dense semantic embeddings via Reciprocal Rank Fusion (RRF), along with transparent source citations and chunk similarity scores.

## 2. Student Performance & Study Analytics Predictor
- **Tech Stack:** Python, Scikit-learn, Pandas, Matplotlib
- **Description:** Developed a machine learning classification and regression pipeline to analyze study habits, attendance, and assignment consistency to predict student academic outcomes and suggest targeted improvements.

## 3. Smart Task & Deadline Manager Web App
- **Tech Stack:** HTML, CSS, JavaScript, Python (Flask)
- **Description:** Created a lightweight productivity web application for university students to organize coursework, prioritize exam revision schedules, and track project milestones.
